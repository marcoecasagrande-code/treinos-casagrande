# Treinos Casagrande

App de treinos da família (musculação, Tabata, treino de domingo, corrida e medidas).
Site: https://marcoecasagrande-code.github.io/treinos-casagrande

- `index.html`: o app (gerado a partir da versão do Claude).
- `firebase-shim.js`: liga o app ao Firebase (login Google + Firestore).
- Os dados ficam no Firebase, protegidos por regras de acesso; não ficam neste repositório.
